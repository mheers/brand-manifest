# Brand assets

Only approved, licensed assets belong in this directory. The paths in `../brand.json` are relative to the `brand/` directory.

- `logo/`: approved logo variants in SVG or other production formats.
- `fonts/`: font files and their license information.
- `imagery/`: approved photography, illustrations and campaign imagery.
- `icons/`: approved icon source files and exports.
- `templates/`: approved reusable layouts and templates.

The SVG files in `logo/` are illustrative placeholders for the template. Replace them before publishing the manifest.
